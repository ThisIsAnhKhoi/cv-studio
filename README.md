# CV Studio — Nền Tảng Tạo & Quản Lý CV Cá Nhân Trực Tuyến

> Dự án web hiện đại hỗ trợ tạo hồ sơ năng lực (CV/Portfolio), tùy biến phong cách, chuyển đổi Dark/Light mode, xuất PDF chuẩn khổ A4 và chia sẻ trực tuyến.

## 🚀 Công Nghệ Sử Dụng
- **Frontend**: React 18+, TypeScript, Vite, Tailwind CSS, Lucide React, Framer Motion
- **Architecture**: 4-Layer Clean Architecture & Template Registry Pattern
- **Quản lý phiên bản**: Git & GitHub (Conventional Commits)
- **Deployment**: Vercel (Frontend), Render / Firebase (Backend & Database)

## 📁 Cấu Trúc Dự Án
Xem chi tiết tại [y_tuong.txt](y_tuong.txt) và theo dõi tiến độ tại [PROJECT_STATUS.md](PROJECT_STATUS.md).

## 🛠️ Hướng Dẫn Cài Đặt & Khởi Chạy
```bash
# 1. Cài đặt thư viện
npm install

# 2. Khởi chạy môi trường phát triển
npm run dev

# 3. Đóng gói cho production
npm run build
```
